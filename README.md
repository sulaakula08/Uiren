# Uiren

Школьная платформа: задания и проверка работ, планы уроков, аналитика класса и
школы, AI-тьютор для учеников. Русский и казахский интерфейс.

## Запуск

```bash
npm install
```

Скопируйте `.env.example` в `.env` и заполните:

- `AUTH_SECRET` — сгенерируйте: `node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"`
- `ANTHROPIC_API_KEY` — получить на https://console.anthropic.com/settings/keys

```bash
npm run setup   # создать схему БД (база при этом пустая)
npm run dev     # http://localhost:3000
```

Без `ANTHROPIC_API_KEY` платформа работает целиком, а AI-кнопки показывают
понятное сообщение вместо ошибки.

## Как начать работу

База изначально пустая — всё создаётся через сайт.

1. **Администратор регистрирует школу** — «Зарегистрировать школу» на главной.
   Дальше мастер из трёх шагов: предметы → классы → код приглашения.
2. **Код приглашения** (шесть символов, например `VHNCV3`) виден в шаге 3
   мастера и вверху панели администратора, там же кнопка «Скопировать».
3. **Учитель** регистрируется по коду и отмечает, какие предметы и в каких
   классах ведёт. После этого может создавать задания.
4. **Ученик** регистрируется по тому же коду и выбирает свой класс из списка.
5. **Родитель** регистрируется после ребёнка и указывает его почту. Аккаунты
   связываются не сразу: ученик подтверждает запрос у себя на странице, и
   только после этого родитель видит оценки. Почту знает вся параллель, а
   доступ к успеваемости — нет, поэтому решает сам ученик.

Привязать ребёнка можно и позже — на странице родителя, по почте. Ученик так же
может позвать родителя со своей страницы; подтверждает всегда вторая сторона.

Аккаунт директора создаёт администратор вручную («Добавить пользователя»):
директор видит аналитику по всей школе, поэтому не выдаётся по публичному коду.

При первом входе каждая роль получает обучающий тур: подсветка элементов
и подсказки, что нажимать. Повторить — по значку «?» в боковой панели.

### Демо-данные (необязательно)

Чтобы посмотреть заполненную платформу, есть скрипт с демо-школой.
**Он полностью очищает базу.**

```bash
npm run db:demo
```

Логины: `teacher@uiren.kz`, `student1@uiren.kz`, `director@uiren.kz`,
`parent@uiren.kz`, `admin@uiren.kz` — пароль у всех `uiren2026`,
код школы `DEMO25`.

## Что умеет

**Учитель** — создаёт задания (AI составляет черновик по теме, учитель правит),
проверяет работы: AI ставит балл и определяет, *почему* ученик ошибся — не понял
концепт, ошибся в вычислении, был невнимателен, не приступал. Дальше строит
разбор класса: где просели, из-за чего и что сделать на следующем уроке. Плюс
планы уроков (КСП) и черновики сообщений родителям.

**Ученик** — видит задания, сдаёт работы, получает разбор своих ошибок и список
личных пробелов. AI-тьютор знает, что проходили в его классе и где он ошибался
в последних работах — и ведёт к ответу, а не выдаёт готовое решение.

**Директор** — динамика по предметам, системно просевшие понятия, активность
учителей, прогноз ЕНТ по классу.

**Родитель** — оценки ребёнка, над чем стоит поработать, сообщения от учителей.

**Администратор** — настройка школы, код приглашения, пользователи, выбор
электронного журнала.

## Стек

Next.js 16 (App Router) · TypeScript · Prisma + SQLite · Tailwind v4 ·
Claude API (`@anthropic-ai/sdk`)

```
src/
  app/
    page.tsx        интро-страница: что это и для кого
    register/       регистрация школы и присоединение по коду
    admin/setup/    мастер настройки школы
    teacher/setup/  учитель отмечает свои предметы и классы
    api/tutor/      стриминг ответов тьютора
  lib/ai/           client.ts (строгий JSON через tool use), tasks.ts, tutor.ts
  lib/tour-steps.ts шаги обучающего тура по ролям
  components/tour   подсветка элементов и подсказки
prisma/             schema.prisma, seed.ts (демо)
```

Структурированные ответы модели идут через `runStructured()` — модель обязана
вызвать инструмент со `strict: true`, чей JSON-Schema и есть контракт ответа;
результат дополнительно валидируется zod. Модели настраиваются через
`UIREN_MODEL_FAST` (проверка, генерация) и `UIREN_MODEL_HEAVY` (аналитика).

Каждый вызов пишется в таблицу `AiLog` — оттуда считается метрика
«часов сэкономлено».
