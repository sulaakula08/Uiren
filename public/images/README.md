# Статические файлы

Всё, что лежит в `public/`, отдаётся с корня сайта. Путь в коде пишется
**без** слова `public`:

| Файл на диске | URL в браузере | Как писать в коде |
| --- | --- | --- |
| `public/images/logo.svg` | `/images/logo.svg` | `src="/images/logo.svg"` |
| `public/favicon.ico` | `/favicon.ico` | подхватывается сам |
| `public/images/school.jpg` | `/images/school.jpg` | `src="/images/school.jpg"` |

## Как вставлять

Используйте `next/image`, а не обычный `<img>`: компонент сам отдаст webp,
подберёт размер под экран и зарезервирует место, чтобы страница не прыгала
при загрузке.

```tsx
import Image from "next/image";

<Image
  src="/images/hero.jpg"
  alt="Учитель проверяет работы"   // обязательно: описание для скринридера
  width={1200}
  height={800}
  priority                          // только для картинки на первом экране
/>;
```

Для фото, которое должно занять весь блок:

```tsx
<div className="relative h-64 w-full overflow-hidden rounded-2xl">
  <Image src="/images/school.jpg" alt="Здание школы" fill className="object-cover" />
</div>
```

## Что стоит помнить

- **Формат.** Фото — `.jpg`, логотипы и иконки — `.svg`. `.png` только там, где
  нужна прозрачность и SVG не подходит.
- **Размер.** Изображения из `public/` не сжимаются при сборке — что положили,
  то и уедет пользователю. Держите файлы до ~300 КБ.
- **Публичность.** Всё в `public/` доступно любому по прямой ссылке, без входа
  в систему. Работы учеников, сканы документов и прочее личное сюда класть
  нельзя — для таких файлов нужно отдельное защищённое хранилище.
- **Имена.** Латиницей, в нижнем регистре, через дефис: `hero-teacher.jpg`.
  Кириллица и пробелы в URL ломаются при деплое.
